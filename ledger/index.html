        Claude work per day

        Logs start on 22 September. Brighter squares cost more, and empty ones had no Claude Code work on this Mac.

        Context per reply

        Average tokens each main-thread reply read, so lower is cheaper. Lime dots mark days with cache rebuilds, sized by how many. Gaps are days without Claude Code work.

        Cost per shipped task, week by week

        Each dot is a task, placed in the week it shipped and coloured by its lead model. The bar marks the week's median. The line is the median of the last 10 shipped tasks, updated as each one ships. Weeks start on Monday, and history begins on 22 September, so this fills in as you work.

        Every task

        A task is a PR, or work committed straight to main and grouped by the issue it names. The square before each title is its lead model. Failed test runs include the failing tests TDD writes on purpose, and reviews are cross-model critiques from Codex or agy.

        The long view

        Codex logs go back to June. Claude Code deleted its own logs after 30 days until 21 October, when that was raised to a year, so its history starts in late September and fills in from here.

        Tokens per month, by tool

        Every token each tool read or wrote, from the per-call logs. Earlier months show no Claude Code because its logs for them are gone. Claude Code's September starts on the 22nd, and the latest month runs to today. Antigravity includes a few replies from the older Gemini CLI.

        What Codex spent its tokens on

        Share of all Codex tokens for this repo. Auto-review is Codex Desktop checking its own actions before running them. Review is the cross-model critique Claude asks for with codex exec.

        How it's measured

        Built from every Claude Code, Codex, Antigravity and Gemini CLI log on Pritesh's Mac, across every project, plus Claude cloud sessions imported by hand, Sable's git history and GitHub. It refreshes every morning.

        API-equivalent cost
        Tokens priced at Claude API list rates: fresh input, cache writes (1.25 times input for 5 minutes, twice input for an hour), cache reads, and output including thinking.
        Cloud sessions
        Claude Code runs in the cloud (claude.ai/code) leave no logs on the Mac. Their token counts are imported by hand from the sessions record, by day, with no task attached. So far: two sessions, 31 Oct to 8 Nov.
        Project
        The folder a run happened in: Sable for its checkout, its worktrees and Claude's scratch folders for it, else the folder under ~/code. An Antigravity run with no folder on record is Sable's when its request names Sable, else Unknown.
        Task
        A Sable GitHub PR. Replies on a feature branch belong to its PR. Replies on main belong to the next commit or PR command in the same session.
        Lead model
        The model that wrote most of a task's output, across Claude Code and Codex agent work.
        Cache rebuild
        A reply, not a session's first, that had to write at least 50,000 tokens and half its context to the cache again. Most come after a gap of an hour or more, when the prompt cache has expired; fewer follow a compaction.
        CI first try
        The first commit CI ran on for that task passed.
        Reworked
        A later fix commit on main, within 14 days, touched the same source files. A rough signal.
        Gemini
        Antigravity (agy) and the older Gemini CLI. Tokens only, with no list prices.
        Call
        One model response: a reply in Claude Code, a model turn in Codex, a generation in Antigravity.
