Definitions

Task
A GitHub PR. Work committed straight to main is grouped by the issue its commit names, or else counts as its own task. A Codex branch that never became a PR is a task named after the branch.
Tied to a task
Replies on a feature branch belong to that branch's PR. Replies on main belong to the next commit or PR command in the same session within 4 hours, or the one just before within 30 minutes.
API-equivalent cost
Tokens priced at Claude API list rates: fresh input, cache writes (1.25 times input for 5 minutes, twice input for an hour), cache reads and output, which includes thinking.
Led
The model that wrote most of a task's output tokens, across Claude Code and Codex agent work.
CI cycle
One commit that CI ran on. A task passed first time when its first cycle passed.
Rework
Later fix commits on main, within 14 days, that touch the same source files. A rough signal, not a verdict.
Cache rebuild
A main-thread reply, not a session's first, that wrote at least 50,000 tokens and at least half its context to the cache.
